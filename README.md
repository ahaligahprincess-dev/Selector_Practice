# Selector Practice

## Overview

This project is a personal profile webpage created to practice **HTML and CSS selectors**. The webpage introduces Princess, a Computer Science student, and includes information about education, career experience, interests, and future goals.

## Features

* Personal introduction and profile section
* Quick facts section
* Career experience section
* Future goals section
* Personal statistics
* Interests including reading, gaming, and learning
* Contact section with email, LinkedIn, and phone links
* Responsive layout for different screen sizes
* Styled using a separate CSS stylesheet

## Technologies Used

* **HTML5** – Used to structure the webpage and organize the content.
* **CSS3** – Used to style the webpage, including colors, spacing, borders, layouts, and responsive design.

## CSS Selector Practice

This project demonstrates several types of CSS selectors, including:

* **Universal selector (`*`)** – Used for general box-sizing rules.
* **Element selectors** – Used to style elements such as `body`, `h1`, `h2`, and `h3`.
* **Class selectors** – Used for sections such as `.hero`, `.panel`, `.stat-card`, and `.detail-card`.
* **ID selector** – The `#goals` ID is used on the future goals section.
* **Descendant selectors** – Used to style elements inside other elements, such as `.hero-card ul`.
* **Adjacent sibling selector** – `.experience-list li + li` is used to add spacing between experience list items.

## Design

The webpage uses a light background with blue and purple accents. Cards use borders, rounded corners, padding, spacing, and shadows to organize the information and create a clean layout.

The CSS also includes responsive media queries so the layout changes for larger screens. On wider screens, the hero section and content sections are arranged into multiple columns.
